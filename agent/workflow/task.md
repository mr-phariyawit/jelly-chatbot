# Short Code: /task
**Trigger:** User wants to start a complex coding task.

## Logic
1. **Analyze:** Read `task.md` and current state.
2. **Plan:** Create `implementation_plan.md` if new feature.
3. **Execute:** Modify code -> Test.
4. **Verify:** Run verification steps.
5. **Update:** Update `task.md` status.
