# Short Code: /learn
**Trigger:** User gives negative feedback or a bug is found.

## Logic
1. **Root Cause:** Analyze why the error occurred.
2. **Rule Update:** Update `agent/rules/*.md` to prevent recurrence.
3. **Memoize:** Add lesson to `agent/memory/lessons.md`.
4. **Fix:** Correct the code.
