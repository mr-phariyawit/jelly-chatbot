# Documentation Standards

## 1. Code Comments
- **Docstrings:** Required for all public functions/classes.
- **Focus:** Explain "Why" and "How", not just "What".

## 2. Artifacts
- **Traceability:** Maintain `task.md`, `implementation_plan.md`, `walkthrough.md`.
- **conciseness:** Keep artifacts readable and to the point.
